# 计算、数据时点与决策口径

本文对应 `indicators-2`、`atomic-v1`。它描述初始实现规则，不代表规则已经过盈利能力验证。实现入口为 `src/jev_trader/indicators.py`、`jev.py` 和 `calendar.py`。

## 数据时点

1. 使用 `Asia/Shanghai` 时间及所选数据提供方的交易日历，15:00 前最多取前一交易日，休市日取最近完成交易日。
2. 获取日线后再次按截止日期裁剪。开高低收、成交量必须齐全且有限，价格为正、成交量非负，日期不得重复，OHLC 必须一致。成交额、换手率允许缺失，不能据此补造数值。
3. 最新日线必须恰好覆盖截止交易日，且有成交。否则不调用模型。缺日线不能可靠区分停牌和上游延迟时，明确报告两种可能，记为失败；已取得零成交日线则按停牌／无成交跳过。
4. 由截断日线构造周／月线，只使用交易日历确认已经结束的周期，节假日提前结束的交易周也可以闭合。当前未结束周／月不参与图表及模型。
5. 前复权历史由数据源返回。增量更新对比 40 个自然日重叠区，价格变化触发全段重建。不同来源分开缓存。上游可重述复权历史，所以截断 K 线日期并不等于保存了该历史日期当时可获得的复权版本。本项目只做最新状态分析，不提供历史时点重放。

默认获取十年历史，至少 260 根日线；指标预热遵循 TA-Lib 定义。较新股票的长期 EMA 仍更受初始化影响。必需历史不足直接过滤；周月或行业参考不足则标注缺失，不填零冒充中性信息。

## 技术事实与形态

- MA20/60 相对位置与近5日方向；MA5/10/20/60 排列；ADX≥25 时才将 DMI 方向作为趋势证据。
- RSI14：50–70为偏多，低于40或≥75为偏空，其他为中性；这只是初始证据标签，不能单独决定买卖。MACD结合零轴、信号线及近3日柱体变化。
- MA5/20、MACD和KDJ交叉检查最近5日严格异号；相等不算已经交叉。量比≥1.3结合当日涨跌形成量价确认，OBV比较20日前。
- 60日区间高低点**不包含当前日**。突破后15日内检查是否仍维持在原边界上方，称为突破维持／失败观察，不声称已出现精确回踩买点。
- 高低拐点需要左右各2根 K 线且极值唯一；最后2根尚未确认的点不能用于趋势线或背离。趋势线取最近120根中的最后两个确认高／低点；背离比较最近60根的两个确认价格拐点，最新点需位于最近20根内。
- RSI、MACD、OBV 背离是规则识别的“候选”，不等于确定反转。缺口需高低价不重叠，且其后的价格尚未完全回补。
- 14类蜡烛形态使用 TA-Lib 默认规则，保留最近3日命中；十字星、纺锤线视为中性，其他按其返回符号标记，证据强度0.6。形态解释明确要求结合趋势与量价背景。
- 批量股票列表不生成市场宽度，不能用选择性样本代替全市场；缺失时明确标注且不使用。若已有同日、同口径的历史全市场缓存，市场宽度为所选交易所和基础过滤口径下，有效样本中收盘高于 MA20 的比例；有效覆盖率需≥80%，只用同日、同股票池缓存。≥60%偏多，≤40%偏空，其余中性。分母包含未能下载的未排除股票，不能靠丢弃失败项夸大覆盖率。

支持／反对来自全部已计算事实，不能为迎合最终判断而删除不利证据。指标数值的方向标签是规则约定；原始指标也会发送给 Jev，以便判断冲突。底层证据都记录日期及指标引用，界面可定位日期。

## Jev 如何参与

调用 [TypeSafe 官方 API](https://docs.typesafe.ai/api) 的 `POST /v1/systemone`，发送结构化状态、问题与模型名。不会发送 API key 到行情提供方，也不发送持仓信息。模型会收到技术指标与英文事实，因此本地运行并不表示推理完全离线。

两个候选窗口各询问七个方向维度的 `Choice`：`bullish / neutral / bearish`；另询问波动不稳定程度 `Noul`。全部八维有效时共16个问题，在一个请求内提交。缺失的方向维度不提问。波动不直接作为看空票，而是压低方向判断的强度。

所有必需问题必须返回正确类型；概率是有限的0–1数值、总和接近1、最高概率选项与返回choice相符。缺失、异常或网络失败均不形成判断。429/503/529最多重试两次，指数退避；认证失败直接返回状态，批量扫描暂停。

## 汇总公式

每个维度方向值 `d = P(bullish) − P(bearish)`。缺失维度的权重不参与分母。

| 维度 | 2–5日 | 5–20日 |
| --- | ---: | ---: |
| 趋势 | 0.20 | 0.28 |
| 动量 | 0.20 | 0.12 |
| 量价 | 0.16 | 0.13 |
| 价格结构 | 0.18 | 0.14 |
| K线形态 | 0.10 | 0.04 |
| 多周期 | 0.06 | 0.19 |
| 相对强弱 | 0.10 | 0.10 |

```text
direction = Σ(w × d) / Σ(w)
score = direction × (1 − risk_damping × risk)
disagreement = Σ(w × abs(d − direction)) / Σ(w)
conviction = abs(score) − 0.1 × disagreement
```

默认 `risk_damping=0.5`。选择 conviction 较高的窗口，平局选5–20日。仅对所选窗口形成一个总判断：score≥0.30买入，≤−0.30卖出，其余持有。买入／卖出还需至少两个不同维度有同向事实支持，否则回到持有。

方向结论的支持证据是同向事实，反对证据是反向事实，中性事实列作背景。持有的支持理由是未达阈值或同向维度不足，较强的方向事实列为反对持有；较弱的候选形态列作背景。没有模型结论时，仅显示偏多／偏空／中性事实。

权重、阈值、窗口选择及事实支持门槛是可检查的初始规则，未做回测。Jev 概率不作为实证上涨概率或交易胜率对用户展示。没有保证适用周期内获利的含义。

## 留存与恢复

分析缓存签名包括股票、已截断状态、数据来源、模型别名、指标及提示版本、权重、阈值和风险衰减。成功响应缓存24小时，同时留存实际返回模型版本、概率及汇总过程，正常报告只输出判断、窗口和证据。实际重新计算时创建独立报告 ID，保留此前快照及审计；有效缓存命中时仍复用原报告。

批量扫描仅处理固定股票列表（去重后最多 50 只），按输入顺序逐只完成行情与模型分析。结果即时保存，不等待整批行情；模型失败立即暂停，连续 3 只数据处理失败且仍有待处理股票时自动暂停。旧全市场任务保留历史但不能恢复。

扫描固定交易日及配置摘要，恢复时不同则拒绝继续；更换 API key 不改变摘要，以便修复认证。CLI与网页通过同一个文件锁串行扫描，暂停在当前股票或准备步骤结束后生效，之后不再处理下一只股票。中止遵守相同停止边界，保留历史与缓存，但该任务不再允许继续或重试。扫描成功项不因失败重试而重复调用；缓存失效或数据变化时需要新分析。

## Tushare 数据口径

- `daily` 价格为未复权；以 `价格 × 当日 adj_factor / 截止日最后一根有效日线的 adj_factor` 计算前复权 OHLC。每根日线都必须有有限正因子，缺失则停止分析；截止日之后的因子不参与。
- `daily.vol` 手乘 100 为股，`daily.amount` 千元乘 1000 为元，`daily_basic.turnover_rate` 保留百分数。成交量和成交额不参与价格复权。
- `index_daily` 的量／额分别为手／千元，`sw_daily` 分别为万股／万元；指数比较只使用价格。
- 行业使用 `index_member_all` 的申万一级代码与 `sw_daily`（申万2021版）配对。当前分类用于最新收盘分析，不构成历史时点行业成员数据库；不把 `stock_basic.industry` 名称映射为申万代码。
- 行情按不重叠、最多1095日窗口请求；股票名单按交易所分别请求，避免单次行数限制截断。缓存包含来源、截止日与历史长度，不混接 AKShare 数据。
